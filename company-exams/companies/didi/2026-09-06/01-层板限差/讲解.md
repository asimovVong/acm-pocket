## 原始完整题目

以下按微信原文转录，保留原变量 m、约束和全部样例；仅统一公式、空格与数字排版。来源：[滴滴9月6日机考笔试真题与解析](https://mp.weixin.qq.com/s/lxkbH776rnz3PgnzkNKE4w)。后面的题意、输入输出与范围解释为学习讲解。

### 题目内容

冷链库要把 m 个已经贴好箱号的周转箱放到 m 层货架上，每层恰好一箱。箱号从 1 到 m，即使两箱高度相同，箱号不同也算不同摆法。从下往上数，第 i 层放的箱子箱号记为 p<sub>i</sub>。

第 i 号箱子的高度是正整数 v<sub>i</sub>。为了不让上层塌得太狠，对所有 1 ≤ i < m，必须满足 v<sub>p<sub>i+1</sub></sub> ≥ v<sub>p<sub>i</sub></sub> − d，也就是上一层最多比下一层矮 d。请计算有多少种排列 p 能摆稳。答案可能很大，输出对 998244353 取模的结果。

约束：

- 2 ≤ m ≤ 200000
- 1 ≤ d ≤ 1000000
- 1 ≤ v<sub>i</sub> ≤ 1000000

### 输入描述

第一行两个整数 m、d（2 ≤ m ≤ 200000，1 ≤ d ≤ 1000000），表示箱子个数和允许的最大下落高度。

第二行 m 个整数 v<sub>1</sub>, v<sub>2</sub>, …, v<sub>m</sub>（1 ≤ v<sub>i</sub> ≤ 1000000），表示各箱高度。

### 输出描述

输出一个整数，即合法摆法数量对 998244353 取模后的结果。

### 样例1

**输入**

```text
3 1
1 2 3
```

**输出**

```text
4
```

**说明**

箱号 1、2、3 的高度分别是 1、2、3。从下到上合法的箱号排列有 [1,2,3]、[1,3,2]、[2,1,3]、[3,2,1]，共 4 种。[2,3,1] 和 [3,1,2] 会从 3 一下子落到 1，超过 d = 1。

### 样例2

**输入**

```text
2 1
8 1
```

**输出**

```text
1
```

**说明**

只能把矮的 1 号箱放下面、高的 8 号箱放上面。反过来上一层会矮 7，超过 d = 1。

### 样例3

**输入**

```text
3 10
4 4 4
```

**输出**

```text
6
```

**说明**

三箱高度相同，怎么摆都不会下落，箱号可任意排列，答案是 3! = 6。

## 题意解释

先把题目中的三样东西分开：**箱号、箱子高度、箱子所在的层数**。

- m：一共有多少个箱子，也有多少层货架。后面的 Python 代码把同一个数量叫 n。
- vᵢ：第 i 号箱子的高度。比如输入高度 8、1，表示 1 号箱高 8，2 号箱高 1。
- pᵢ：从下往上数，第 i 层摆的是几号箱子。p 是我们要安排的箱号顺序。
- v[p[i]]：先找到第 i 层的箱号，再查这个箱子的高度。
- d：相邻两层从下到上最多允许降低多少高度。

公式 v[p[i+1]] ≥ v[p[i]] − d 的意思是：**上层的高度，不能小于“下层高度减 d”**。

例如下层高 3、d=1，那么上层至少要高 2。上层高 2、3、8 都合法；高 1 就不合法。只限制下降，升高没有限制，不要理解成“两个高度的绝对差不超过 d”。

题面让你求的是“合法摆法有多少种”，不是最高能放多少箱子，也不是输出一种摆法。每个箱子恰好用一次。

**原文样例 2 的箱号笔误：**原文写“矮的 1 号箱、高的 8 号箱”，实际混用了高度和箱号。m=2，所以箱号只有 1、2。高度输入是 8、1，正确摆法是从下到上放 2 号箱、1 号箱，即箱号顺序 [2,1]、高度顺序 [1,8]。上面的原题区保留原文，这里单独说明。

样例 3 中三个箱子都高 4，仍是三个不同编号的箱子。把它们叫 A、B、C，ABC 与 BAC 是不同摆法，共 3×2×1=6 种。

## 输入解释

第一行有两个数：第一个是箱子数量 m，第二个是下降上限 d。第二行有 m 个数，依次给出 1 号到 m 号箱子的高度。

把样例 1 逐项拆开：

```text
3 1        → 3 个箱子，允许相邻两层从下到上最多降低 1
1 2 3      → 1 号箱高 1，2 号箱高 2，3 号箱高 3
```

**第二行是“按箱号记录的高度”，不是已经决定好的摆放顺序。**你要考虑这些箱子重新排列后的各种摆法。

输入中没有 p，因为 p 正是程序要统计的排列。也没有开头的测试组数 T；第一行的 3 就是箱子数量，不代表有三组测试。

Python 中可先写 `n, d = map(int, input().split())`。这里把题面的 m 命名为 n，含义完全一样；再读入高度列表 heights。题面箱号从 1 开始，Python 列表下标从 0 开始，例如 1 号箱的高度存放在 `heights[0]`。

## 输出解释

只输出一个整数：合法排列数量对 998244353 取模后的结果，不输出排列本身。

样例 1 有四种合法箱号顺序：[1,2,3]、[1,3,2]、[2,1,3]、[3,2,1]，所以打印 `4`。

“取模”就是求除法的余数：例如 `10 % 3 = 1`。本题用 `真实数量 % 998244353`。当数量小于 998244353 时，取模后不变，因此样例中的 4、1、6 直接输出即可；不是每个答案都要减一次这个数。

计算时可以每乘一次就取模，避免计数变成极大的整数。Python 代码中的 `MOD = 998244353` 只是给题目规定的模数取一个名字。

## 范围解释

- **2 ≤ m ≤ 200000**：最少 2 个箱子，最多 20 万个。20 万是“有多少个数”，不是箱子的最大高度。
- **1 ≤ d ≤ 1000000**：允许下降的幅度是 1 到 100 万之间的整数。小于 d 或恰好等于 d 的下降都合法。
- **1 ≤ vᵢ ≤ 1000000**：每个箱子的高度都是正整数，最大 100 万；高度可以重复，也不保证已经排序。
- **为什么不能枚举所有排列**：仅 10 个不同箱子就有 10!=3628800 种排列，20 万个更不可能逐一检查。
- **为什么也要避免两重全扫描**：20 万的平方是 400 亿，逐个比较所有箱子对成本过高。需要接近 O(m log m) 或 O(m) 的做法。
- **箱子高度不大，不等于答案不大**：如果所有箱子一样高，m! 种排列都合法，所以题目才要求对计数取模。

这些范围是输入保证，通常不用在提交代码中逐一校验；它们主要帮助你选择能在大输入下运行的算法。

## 先想一种不会漏的构造方法

直接枚举排列需要 n! 次，n 达到 20 万时完全不可行。我们换一个角度：**先摆高箱子，再把矮箱子一个个插进去。**

用 [1,2,3]、d = 1 演示：

1. 先摆 3，只有 [3]，共 1 种。
2. 插入 2：可以放在开头得到 [2,3]；也可以接在 3 后面得到 [3,2]，共 2 个位置。
3. 插入 1：无论刚才得到哪一种排列，都可以放在开头，也可以接在 2 后面。但是不能接在 3 后面，那里会降低 2。所以每一种已有排列又有 2 个位置。

总数就是 1 × 2 × 2 = 4。

“放在开头”代表放到整套架子的最下方。此时它后面都是不低于它的箱子，不会发生过大的下降。

## 为什么每次都能直接乘

设当前插入的箱子高度是 x。之前摆好的箱子都不比 x 矮。

- 放在开头总是合法：后面是更高或一样高的箱子。
- 放在某个高度 y 的箱子后面：需要 y - x ≤ d，也就是 y ≤ x + d。
- 插入后，x 与其后继之间总是升高或持平，所以不用再检查那一侧。

因此，合法插入位置只取决于**已有箱子中有几个高度 ≤ x+d**，与这些箱子的具体顺序无关。每一种已有排列都有同样多的选择，乘法原理就能使用。

还要保证不漏、不重：从一个最终合法排列中，删除这次插入的最矮箱子，能唯一恢复上一步的排列和插入位置。若它原本在 y 与 z 之间，已有 y-x≤d 且 z≥x，所以 y-z≤d，删除后仍合法。同高箱子先按固定编号顺序处理，也有同样的一一对应关系。

## 把插入位置数量写成 right - i

把高度从小到大排序，叫 a。对下标 i，假想比它靠右的箱子已经放好了。

令 right 指向第一个满足 a[right] > a[i]+d 的位置。如果没有，就令 right=n。

```text
下标：       i       i+1   ...   right-1      right
角色：     当前箱子    可以接在它们后面         超过限制
```

已有、且高度不超过 a[i]+d 的箱子是 a[i+1:right]，一共 right-i-1 个。加上最开头的一个位置，就是 right-i。

因此答案是所有 (right-i) 的乘积。**不是把这些数量加起来，也不需要再乘一次相同高度的阶乘。**

虽然证明时从高到矮插入，代码可以从小到大计算每个乘数，因为乘法顺序不影响答案。

## 双指针为什么更快

a 已经排好序。当 i 增大时，a[i]+d 不会减小，right 就不需要后退。

对 [1,2,3]、d=1：

```text
 i   a[i]   允许的最高值   right   right-i   累计答案
 0    1         2           2        2          2
 1    2         3           3        2          4
 2    3         4           3        1          4
```

right 是“第一个不合法的位置”，所以计数时不包含它。while 内使用 ≤，因为恰好下降 d 仍然合法。

## 完整 Python 程序

```python
"""滴滴 2026-09-06：层板限差。排列按从下往上的顺序理解。"""
import sys

MOD = 998244353


def count_arrangements(heights, d):
    a = sorted(heights)
    n = len(a)
    answer = 1
    right = 0

    for i in range(n):
        # right 最终停在第一个大于 a[i] + d 的位置；可以等于 n。
        while right < n and a[right] <= a[i] + d:
            right += 1

        # 假想从高到矮插入 a[i]：
        # 能接在 a[i] 前面的较高箱子有 right-i-1 个，
        # 再加上放到整个排列开头这 1 种位置，共 right-i 种。
        choices = right - i
        answer = answer * choices % MOD

    return answer


def solve():
    input = sys.stdin.readline
    n, d = map(int, input().split())
    heights = list(map(int, sys.stdin.read().split()))
    print(count_arrangements(heights, d))


if __name__ == '__main__':
    solve()
```

## 对照代码看变量

- a：排好序的高度列表，原来的 heights 不会被修改。
- i：正在计算哪个箱子的插入位置数量。
- right：窗口右边界，不包含在合法窗口内，可以等于 n。
- choices：当前箱子可插入的位置数。
- answer：目前所有 choices 的乘积，每步取模。
- sys.stdin.readline() 读取第一行；sys.stdin.read() 读取剩余整数，也能容忍高度跨行。

## 复杂度与容易写错的地方

排序 O(n log n)，双指针扫描 O(n)，总时间 O(n log n)。排序后的数组占 O(n) 额外空间。

- 不要写 abs(上层-下层)≤d，那会错杀合法的升高。
- while 用 ≤，不是 <。
- right 不要每轮重新从 i 开始，否则退化到 O(n²)。
- 乘数是 right-i；写成 right-i-1 会漏掉开头的位置。
- 相同高度仍分别计算，公式已经自动包含它们的排列数。
- 每乘一次就取模，避免无意义的大整数增长。
