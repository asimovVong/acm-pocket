# ACM 随手练 · ACM Pocket

### 为面试和笔试，把灵神的力扣解法练成 ACM 完整程序。

为了准备算法面试和笔试，跟着 **灵茶山艾府（灵神）B 站《基础算法精讲》**学习、掌握对应的 LeetCode 解法，是本项目的出发点。

但面对采用 **ACM 模式**的面试与笔试，即使系列里的力扣算法写法都已经掌握，通常还要自己在本地逐题重新写一遍 ACM 完整程序：补齐标准库导入、输入输出、链表和树等数据结构的定义与构建，以及程序入口，再准备测试输入进行验证。

**逐题改写、测试和整理既麻烦，分散在本地的文件也不好回顾。** 因此开发了 **ACM 随手练**：按灵神的主讲题目与对应解法，集中提供完整 ACM 参考、库导入说明、数据结构构建和运行验证，方便快速查阅、自己练习与考前复习。

**准备面试 / 笔试 → 学习灵神的力扣解法 → 在这里练习对应 ACM 写法 → 验证与回顾。**

**60 道主讲题 · 253 组自编用例 · 独立练习 / 参考双面板 · 浏览器内 Python · `acm` 一键启动**

练习台原创代码以 [MIT 许可证](LICENSE) 开源。课程、题解、题目与截图保留原作者权利，具体范围见[第三方来源与许可说明](THIRD_PARTY_NOTICES.md)。

## 为什么需要这个练习台？

在 LeetCode 中，练习者通常只需实现指定函数，平台负责调用；在采用 ACM 模式的考试中，还需要自己组织完整程序，从标准输入读取数据，再按要求输出答案。

同一道题的算法已经掌握，迁移到 ACM 时仍有这些准备工作：

| 要补齐的环节 | 反复在本地整理的麻烦 | 练习台提供什么 |
| --- | --- | --- |
| 标准库导入 | 题解里用了 `Counter`、`deque`、`inf`，完整程序需要补什么？ | 每题列出参考写法的导入项及用途 |
| 输入、输出与程序入口 | 核心函数之外，还要读取参数、调用算法并输出答案 | 每题明确的 I/O 约定和完整可运行参考 |
| 数据结构 | 链表和树题在本地需要自己定义节点、建立结构、定位目标节点 | 节点定义、构建函数及必要的查找辅助函数 |
| 手动复写 | 对照参考时，需要保留自己的尝试 | 可编辑尝试区与只读参考区分开，分别运行 |
| 运行验证 | 每道题都要准备输入、预期输出和核对方式 | 内置用例、自定义输入和按题型核对结果 |
| 考前回顾 | 本地文件和笔记分散，不容易找回某道题的完整写法 | 按题号、题名或分类查找，集中查看参考与已保存草稿 |

**核心价值：减少算法面试与笔试备考中，逐题在本地改写、测试和整理 ACM 程序的重复工作，让已经掌握的力扣解法有对应的完整写法可查、可练、可验证、可回顾。**

## 适合谁？

- 为算法面试与笔试学习灵神《基础算法精讲》，掌握力扣解法后需要逐题练习对应 ACM 写法的人。
- 熟悉 LeetCode 函数式答题、正在准备采用 ACM 模式的算法面试或笔试的人。
- 希望考前快速回顾常用库、输入输出和数据结构构建方式的人。

这个需求也适用于跟其他课程、题单练过算法的人：熟悉核心函数之后，需要把它接到完整的输入输出流程中，并集中练习和复习。当前题库具体围绕灵神的课程整理。

ACM 模式要求完整的输入输出程序，但各场考试的输入格式并不统一。本项目为原本采用函数接口的题目制定了练习用 I/O 约定，实际考试时仍应按题目要求调整。

## 怎么用它备考？

1. **查写法**：按熟悉的题号找到完整 ACM 参考，查看导入、输入输出和辅助函数。
2. **自己练**：在独立尝试区复写或修改程序，需要时对照参考。
3. **做验证**：运行内置用例或自定义输入，检查完整程序的结果。
4. **快回顾**：下次用 `acm` 打开，按题检索参考、草稿与手动完成进度。

## 快速开始

从 [Releases 下载页](https://github.com/asimovVong/acm-pocket/releases/latest) 选择对应系统的 ZIP，**先解压整个文件夹**，再双击启动。需要 Python 3.9+ 和现代浏览器，无需管理员权限，也不用安装 pip/npm 依赖。

| 系统 | 下载包 | 双击打开练习台 | 安装 `acm` 命令（可选） |
| --- | --- | --- | --- |
| Windows 10 / 11 | 文件名以 `Windows.zip` 结尾 | `启动ACM.cmd` | `安装快捷命令.cmd` |
| macOS | 文件名以 `macOS.zip` 结尾 | `启动ACM.command` | `安装快捷命令.command` |

安装快捷命令后，重新打开终端，在任意目录输入：

```bash
acm
```

第一次运行需要联网加载浏览器中的 Python 环境 Pyodide。**ZIP 包含完整网站和启动器，不包含系统 Python、离线运行时或浏览器中的个人草稿。**

### Windows 安装与打开

1. 若未安装 Python 3.9+，先从 [python.org](https://www.python.org/downloads/windows/) 安装。保留 Python 启动器，或勾选 **Add python.exe to PATH**，让 `py -3` 或 `python` 至少一个命令可用。
2. 下载 `ACM-Pocket-版本号-Windows.zip`，右键「全部解压」，把整个文件夹放到固定位置，支持中文和空格路径。
3. 双击 `启动ACM.cmd`，练习台会在默认浏览器打开：<http://127.0.0.1:8765/>。
4. 想用快捷命令，再双击一次 `安装快捷命令.cmd`。**完全退出 Windows Terminal、PowerShell 或 CMD 后重新打开**，输入 `acm`。如果还识别不到命令，注销并重新登录 Windows。

快捷命令安装到 `%LOCALAPPDATA%\ACMPocket\bin\acm.cmd`，只向当前用户的 PATH 添加目录，保留原有设置。无需管理员权限，不修改 PowerShell 执行策略。安装后保留原文件夹及 Python 安装；移动启动包或更换 Python 位置后，检查并删除旧的这个 `acm.cmd`，再运行新包的安装器。

没有找到 Python 时，启动窗口会提示安装方法并停留；服务端口被其他程序占用时，会提示错误并保留该程序。
如果当前 PATH 中已有其他工具的 `acm` 命令，安装器会提示冲突并保留原设置；仍可直接双击 `启动ACM.cmd` 使用。

### macOS 安装与打开

1. 若未安装 Python 3.9+，先从 [python.org](https://www.python.org/downloads/macos/) 安装。
2. 下载 `ACM-Pocket-版本号-macOS.zip`，解压到固定位置，双击 `启动ACM.command`。
3. 想用快捷命令，双击一次 `安装快捷命令.command`，然后新开终端输入 `acm`。

命令安装在 `~/.local/bin/acm`，指向当前文件夹的 `launcher.py`；安装器按需将该目录加入 zsh/bash 的 PATH。安装后请保留此文件夹。若要迁移安装，确认 `~/.local/bin/acm` 是旧包的快捷链接后，只移除该链接，再运行新包的安装器。

### 日常使用

两种系统的一键启动都会检查 `127.0.0.1:8765`：已有练习台就直接打开，未运行则后台启动。**可以关闭启动终端；电脑重启后，再输入 `acm` 或双击启动文件。**

- `acm --no-open`：只启动服务，不打开网页。
- `acm --help`：查看帮助。
- 个人草稿和完成进度保存在浏览器中。继续使用同一个浏览器和原地址，可以读取原有草稿；重要代码可以从练习台下载留存。

### 从源码运行（macOS / Linux / Windows）

```bash
git clone https://github.com/asimovVong/acm-pocket.git
cd acm-pocket
python3 launcher.py
```

Windows 可将 `python3` 换成 `py -3`。也可以使用下面的静态服务器方式，手动启动时请保持终端运行。

### 手动启动

```bash
# 在项目文件夹中执行
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器访问 <http://127.0.0.1:8765>。首次加载需要联网取得 Pyodide 314.0.7；右上角显示 Python 就绪后即可运行。无需安装第三方 Python 库或 Node 依赖。

## 刷题

1. 点击 **查找 / 切换题目**，按题号、名称或算法分类查找；也可以筛选未完成题目。
2. 查看左侧本题的 **ACM 输入和输出约定**。各题格式不同，不能统一套用 209 的格式。
3. 在 **我的尝试** 中完成算法。链表和树提供真实节点及建结构辅助函数；点击 **解题区** 直接跳到要写的函数。
4. **参考模板 · 完整 ACM** 展示根据灵茶山艾府对应题解适配的完整 Python 程序，并列出选用版本、导入项及用途、题解直链。宽屏并排显示，窄屏上下排列；可以收起参考专注练习。
5. 「运行我的代码」执行当前输入；「验证本题」运行全部内置用例。参考面板的「运行参考」「验证参考」直接执行只读参考代码，结果标题标注「参考模板」，不替换自己的草稿。参考可复制或下载。
6. 能独立完成后，手动点击 **标记已完成**。可点击撤销，样例通过不会自动改变学习进度。

「自由练习」可运行题库之外的个人 Python 算法程序，自行填写输入和预期输出。

快捷键：Tab/Shift+Tab 缩进、回车延续缩进、Cmd/Ctrl+Enter 运行。支持下载当前程序为 main.py。

## 判题约定

- 标量题：按空白分隔的 token 比较，忽略空格和换行数量。例如 `2.0` 不等于 `2`。
- 数组和结构题：用 `print(json.dumps(answer, ensure_ascii=False))` 输出 JSON。
- 排列、括号序列、N 皇后等解集合：忽略最外层顺序，保持单个解内部的语义顺序。
- 子集和组合：允许解集合顺序、组合内部顺序不同，但重复项仍会被检查。
- 162 寻找峰值：按当前数组验证任意合法峰值下标，预期输出仅是一个示例。
- 关闭自动核对可以只运行；开启核对且预期留空表示要求空输出。

修改代码、输入或预期输出后，旧验证状态会失效，并提示重新运行。

## 草稿与进度

每题和自由练习分别保存到当前浏览器 localStorage（`acm-practice-v2`）。第一次打开新版会迁移旧版 209 和自由练习的草稿；旧的 `acm-practice-v1` 键保留，迁移不会覆盖已有新版草稿。首次进度只标记用户已明确报告做完的 42《接雨水》；以后由用户手动管理。

更换浏览器或清理站点数据会影响本地草稿，请下载需要长期保存的代码。数据不会同步到其他设备。

## 运行边界

代码在浏览器 Pyodide module Worker 中执行，不在本机 Python 进程中执行。每组最多运行 3 秒（初始化不计入），超时或手动停止后重建 Worker。题库模式每个标准输出流最多 8 MiB，自由练习为 64 KiB。预览最多显示前 16000 字符，判题使用完整输出。遇到本页资源上限时，应缩小数据或下载代码本地运行。

本地用例用于快速验证，不等同于力扣完整评测，也不会检测所有复杂度或内部操作要求。支持 Python 标准库；这是个人练习工具，不是运行不可信代码的公共服务。

## 完整 ACM 参考

`data/references-{arrays,structures,dp}.json` 与练习草稿分开存放。每道题选取对应作者文章中的一个明确版本，补齐标准库、节点定义、读入和输出；ACM 封装和中文导入说明由本项目整理，原作者的力扣代码并非原生 ACM 格式。第 3 题按本次学习需要将原文的 `defaultdict(int)` 等价适配为 `Counter`，页面明确注明。

参考程序与左侧题目的本页输入约定一致，实际笔试仍需按考场格式调整。`node --test tests/references.test.mjs` 用生产运行适配器执行所有参考程序，并调用同一个网页判题器核对固定用例。参考加载失败时仍可以继续编写和运行个人尝试。
