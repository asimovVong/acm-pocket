# ACM 随手练 · ACM Pocket

### 从会写 LeetCode，到能交 ACM 完整程序。

算法想明白了，却卡在 `import`、输入解析、建树建链和输出格式？

**ACM 随手练**把这些环节放进同一个练习台：左边自己写，右边看完整参考，写完直接跑用例。把「看懂题解」变成一次真正的独立练习。

**60 道主讲题 · 253 组自编用例 · Python 浏览器内运行 · 一条 `acm` 命令启动**

它围绕灵茶山艾府「基础算法精讲」的主讲题单整理，覆盖双指针、滑动窗口、二分、链表、树、回溯、动态规划、单调栈与单调队列。参考程序保留对应题解链接，并补齐本页约定下的 ACM 输入输出。

## 为什么做这个项目？

在 LeetCode，你往往只需要写一个函数；换到 ACM 模式，还得自己读输入、建数据结构、调用算法、打印结果。

这个练习台把完整过程串起来：

```text
选一道题 → 看输入输出约定 → 自己写完整程序 → 跑用例
                                           ↓
                                对照参考 → 修改 → 再验证
```

| 刷到一半想下次接着写 | 每题草稿、输入和手动完成标记保存在当前浏览器 |
| 想临时跑一道题库之外的题 | 自由练习支持自己的代码、输入和预期输出 |

还附有公司笔试学习手册，包含两道题的题意、样例、推导与交互演示。来源及核对边界见 [公司笔试手册](company-exams/README.md)。

## 快速开始

**macOS：**从 [Releases](https://github.com/asimovVong/acm-pocket/releases/latest) 下载启动包，解压后双击 `启动ACM.command`。需要 macOS、Python 3 和现代浏览器。

想在任意终端输入 `acm`？双击一次 `安装快捷命令.command`，然后新开终端：

```bash
acm
```

**从源码运行（macOS / Linux / Windows）：**

```bash
git clone https://github.com/asimovVong/acm-pocket.git
cd acm-pocket
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8765/>。Windows 可将 `python3` 换成 `py -3`。跨平台手动启动时请保持终端运行；一键后台启动器适用于 macOS。

首次运行需要联网加载 Pyodide；无需安装 pip/npm 依赖即可使用网站。**这不是完全离线包，ZIP 也不包含浏览器中的个人草稿。**

## 打开

### 一键启动（macOS）

这个启动包叫 **ACM 随手练**，快捷命令是 **`acm`**。

首次使用：把整个文件夹放到固定位置，双击 `安装快捷命令.command`，然后新开一个终端。
之后在任意目录输入：

```bash
acm
```

自动检查 `127.0.0.1:8765`：已有练习台就直接打开；未运行则后台启动后打开默认浏览器。
可以关闭启动终端；电脑重启后，再输入 `acm`。也可以直接双击 `启动ACM.command`，不必安装快捷命令。
若其他程序占用了端口，会提示并保留该程序，不会自动切换地址。

可选命令：`acm --no-open` 只启动服务，`acm --help` 查看帮助。
命令安装在 `~/.local/bin/acm`，指向当前文件夹的 `launcher.py`；安装器按需将该目录加入 zsh/bash 的 PATH。
安装后请保留此文件夹。若要迁移安装，确认 `~/.local/bin/acm` 是旧包的快捷链接后，只移除该链接，再运行新包的安装器。

**运行条件：macOS、Python 3、现代浏览器。** 如果没有 Python 3，请先从 python.org 安装。
包内包含完整网站、题库、参考模板、公司笔试资料和测试；浏览器 Python 运行环境 Pyodide 首次需要联网下载，此包不是离线运行时安装包。
个人草稿和完成进度保存在浏览器中，不包含在 ZIP 中。继续使用同一个浏览器和原地址，可以读取该浏览器原有的草稿。

### 手动启动

```bash
# 在项目文件夹中执行

```

浏览器访问 <http://127.0.0.1:8765>。首次加载需要联网取得 Pyodide 314.0.7；右上角显示 Python 就绪后即可运行。无需安装第三方 Python 库或 Node 依赖。

## 刷题

1. 点击 **查找 / 切换题目**，按题号、名称或算法分类查找；也可以筛选未完成题目。
2. 查看左侧本题的 **ACM 输入和输出约定**。各题格式不同，不能统一套用 209 的格式。
3. 在 **我的尝试** 中完成算法。链表和树提供真实节点及建结构辅助函数；点击 **解题区** 直接跳到要写的函数。
4. **参考模板 · 完整 ACM** 展示根据灵茶山艾府对应题解适配的完整 Python 程序，并列出选用版本、导入项及用途、题解直链。宽屏并排显示，窄屏上下排列；可以收起参考专注练习。
5. 「运行我的代码」执行当前输入；「验证本题」运行全部内置用例。参考面板的「运行参考」「验证参考」直接执行只读参考代码，结果标题标注「参考模板」，不替换自己的草稿。参考可复制或下载。
6. 能独立完成后，手动点击 **标记已完成**。可点击撤销，样例通过不会自动改变学习进度。

「自由练习」可运行题库之外的个人 Python 算法程序，自行填写输入和预期输出。

快捷键：Tab/Shift+Tab 缩进、回车延续缩进、Cmd/Ctrl+Enter 运行。支持下载当前程序为 main.py。

## 判题约定

- 标量题：按空白分隔的 token 比较，忽略空格和换行数量。例如 `2.0` 不等于 `2`。
- 数组和结构题：用 `print(json.dumps(answer, ensure_ascii=False))` 输出 JSON。
- 排列、括号序列、N 皇后等解集合：忽略最外层顺序，保持单个解内部的语义顺序。
- 子集和组合：允许解集合顺序、组合内部顺序不同，但重复项仍会被检查。
- 162 寻找峰值：按当前数组验证任意合法峰值下标，预期输出仅是一个示例。
- 关闭自动核对可以只运行；开启核对且预期留空表示要求空输出。

修改代码、输入或预期输出后，旧验证状态会失效，并提示重新运行。

## 草稿与进度

每题和自由练习分别保存到当前浏览器 localStorage（`acm-practice-v2`）。第一次打开新版会迁移旧版 209 和自由练习的草稿；旧的 `acm-practice-v1` 键保留，迁移不会覆盖已有新版草稿。首次进度只标记用户已明确报告做完的 42《接雨水》；以后由用户手动管理。

更换浏览器或清理站点数据会影响本地草稿，请下载需要长期保存的代码。数据不会同步到其他设备。

## 运行边界

代码在浏览器 Pyodide module Worker 中执行，不在本机 Python 进程中执行。每组最多运行 3 秒（初始化不计入），超时或手动停止后重建 Worker。题库模式每个标准输出流最多 8 MiB，自由练习为 64 KiB。预览最多显示前 16000 字符，判题使用完整输出。遇到本页资源上限时，应缩小数据或下载代码本地运行。

本地用例用于快速验证，不等同于力扣完整评测，也不会检测所有复杂度或内部操作要求。支持 Python 标准库；这是个人练习工具，不是运行不可信代码的公共服务。

## 题源与验证

题目来自[作者配套题单](https://github.com/EndlessCheng/codeforces-go/blob/master/leetcode/README.md)，每题可打开力扣原题。60 题按首次出现的课程顺序排列，42 在第 2/26 集重复出现只收录一次；作者列出的 52《N 皇后 II》也收录。课后拓展题未纳入。


固定预期值由独立参考算法核验，各题模板也经过输入输出适配测试。详见 [VERIFICATION.md](VERIFICATION.md)。

## 完整 ACM 参考

`data/references-{arrays,structures,dp}.json` 与练习草稿分开存放。每道题选取对应作者文章中的一个明确版本，补齐标准库、节点定义、读入和输出；ACM 封装和中文导入说明由本项目整理，原作者的力扣代码并非原生 ACM 格式。第 3 题按本次学习需要将原文的 `defaultdict(int)` 等价适配为 `Counter`，页面明确注明。

参考程序与左侧题目的本页输入约定一致，实际笔试仍需按考场格式调整。`node --test tests/references.test.mjs` 用生产运行适配器执行所有参考程序，并调用同一个网页判题器核对固定用例。参考加载失败时仍可以继续编写和运行个人尝试。
